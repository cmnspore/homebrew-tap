# Code Mycelial Network (CMN)

A sovereign-first protocol for code distribution and evolution tracking. Domains publish signed, hash-verified packages — no central registry.

Homepage: https://cmn.dev

## Install

    brew install cmnspore/tap/<formula>

## Formulas

| Formula | Description |
|---|---|
| [hypha](Formula/hypha.rb) | The reference CMN client CLI — release spores, query synapses, resolve bonds, and manage your local mycelium. |
| [synapse](Formula/synapse.rb) | The reference CMN indexer — ingests signed manifests, indexes spores and myceliums, serves discovery queries, and syncs across instances via Nostr. |
